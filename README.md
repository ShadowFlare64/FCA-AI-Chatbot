# Open Chat AI

Open Chat AI is an interactive chatbot web application built with HTML, CSS, JavaScript, and the Google Gemini API.

## Features

- AI-generated responses using the Gemini API
- Custom pirate-style AI personality
- Speech-to-text microphone input
- Text-to-speech AI responses
- Bookmark AI messages
- Persistent chat history using local storage
- Clear and delete message functionality

## Technologies

- HTML
- CSS
- JavaScript
- Google Gemini API
- Web Speech API
- Local Storage

## Running the Project

1. Clone or download the repository.
2. Open `chatbot.html` in a web browser.
3. Enter your Gemini API key when prompted.
4. Start chatting.

## API Key

The Gemini API key is not stored in the source code. It is entered by the user and stored only for the current browser session.

You can create a Gemini API key through Google AI Studio.

## Project Background

This project was originally developed as part of the Fundamentals of Computing Association and was later completed and expanded with additional chatbot functionality.
